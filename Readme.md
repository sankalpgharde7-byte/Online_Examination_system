Online Examination System
Project Information
PS Number: 53
Project Title: Online Examination System
Programming Language: Python 3
1. Introduction

The Online Examination System is a console-based Python project that allows students to attempt multiple-choice questions. It checks the answers and calculates the final examination result.

2. Objectives
To conduct a simple multiple-choice examination.
To allow students to answer or skip questions.
To validate user input.
To calculate marks and percentage.
To display Pass or Fail results.

3. Technologies Used
Python 3
Visual Studio Code

4. Python Concepts Used
Lists
Dictionaries
Functions
For loops and while loops
Conditional statements
Score calculation

5. Features
Five multiple-choice questions.
Four options for each question.
Option to skip questions using 's'.
Invalid input validation.
Automatic score calculation.
Final result with percentage and Pass/Fail status.

6. Marking Scheme
Total questions: 5
Marks per question: 2
Total marks: 10
Passing percentage: 40%

7. How to Run the Project
Install Python 3.
Download or clone this repository.
Open the project folder in VS Code.
Open the terminal.
Run the following command:
bash
python online_exam.py

8. Expected Result

The program displays the number of correct, wrong and skipped answers, total score, percentage and final examination result.

9. Conclusion

This project demonstrates the basic use of Python programming concepts to create a simple examination system. It helps understand data storage, loops, functions, input validation and decision-making in Python.
